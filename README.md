# 🐍 Snake

A classic Snake game built with Python and Pygame, featuring a clean dark UI with a green-on-black aesthetic.

## Requirements

- Python 3.7+
- Pygame

Install Pygame with:

```bash
pip install pygame
```

## Running the Game

```bash
python snake.py
```

## Controls

| Key | Action |
|-----|--------|
| `↑ / W` | Move up |
| `↓ / S` | Move down |
| `← / A` | Move left |
| `→ / D` | Move right |
| `Space / Enter` | Start / Pause / Resume / Restart |

## How to Play

1. Press **Space** or **Enter** on the start screen to begin.
2. Guide the snake to eat the red food pellets — each one grows your snake and adds to your score.
3. Avoid hitting the walls or your own tail, or it's game over.
4. Your best score is tracked for the session.

## Features

- 20×20 grid with smooth dark theme
- Gradient-colored snake body (bright head fades to dark tail)
- HUD showing current score and session best
- Pause/resume support
- Game over and start overlays
